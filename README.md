# Artisan Pro

Application web modulaire pour petits artisans, sans installation requise.

## Modules

| Module | Description |
|--------|-------------|
| **Clients** | Carnet de contacts clients (ajout, modification, recherche) |
| **Devis** | Création de devis avec lignes détaillées et statuts |
| **Chantiers** | Suivi d'avancement des projets avec barre de progression |
| **Matériaux** | Gestion du stock avec calcul de valeur automatique |

## Utilisation

Ouvrir le fichier `index.html` dans un navigateur — aucune installation ni serveur requis.

Les données sont sauvegardées localement dans le navigateur (localStorage).

## Structure du projet

```
Projet-N/
├── index.html        ← Page principale
├── css/
│   └── style.css     ← Styles de l'interface
└── js/
    └── app.js        ← Logique de l'application
```

## Technologies

- HTML5 / CSS3 / JavaScript vanilla
- localStorage pour la persistance des données
